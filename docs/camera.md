# 相機設定與影像調整

[返回 README](../README.md)

相機設定位於「採集與匯入 → 相機採集」右上角的「相機設定」。面板可捲動；停止相機、擷取畫格固定在底部。影像處理與目標區域工具仍在獨立的「影像工具」面板。

![相機設定面板與固定擷取操作列（合成影像示範）](images/camera-settings.png)

## 輸出模式

| 欄位 | 行為 |
| --- | --- |
| 輸入裝置 | 停止後選擇裝置；偵測會重新讀取 DirectShow 模式清單。 |
| 輸出格式 | 自動模式優先選擇符合條件的 MJPG；也可明確選擇裝置回報的格式。 |
| 解析度、FPS | FPS 提示與有效範圍依解析度及格式連動；驅動提供的範圍仍需實際套用確認。 |
| 自訂解析度 | 手動設定寬高及 FPS，啟動後檢查回報結果；不保證裝置接受。 |
| 套用並重新啟動 | 先檢查表單，再停止並重啟相機，保留當下已回讀的影像參數。停止逾時時不會另開相機。 |
| 預覽更新率 | 5／10／15／30 FPS，控制畫面請求頻率，與擷取及錄影設定分開。 |

錄影、自動擷取、啟動與停止期間無法重設輸出模式。解析度改變時，既有目標區域需重新繪製。

上方狀態列的「回報 FPS」來自驅動；「擷取 FPS」由擷取迴圈時間戳計算；「預覽 FPS」為畫面載入完成的更新頻率，同一相機畫格可能顯示多次。這三個值可能不同。預覽更新率是請求間隔目標，解碼、網頁與系統負載會降低實際更新速度。

要求與回報的解析度、FPS、格式不一致時，面板會列出差異。累積至少 30 張畫格且擷取速率低於要求／回報的 70% 時，顯示低幀率提示；提示本身不代表已確認原因。

## 影像調整

啟動後依裝置能力顯示曝光、增益、白平衡與對焦。進階設定預設收合，包含可用的亮度、對比、飽和度、銳利度、Gamma 與背光補償。

- 每個欄位使用驅動回報的最小值、最大值、步進值及自動／手動能力，數字使用驅動原生單位。
- 支援自動模式時顯示勾選框；開啟自動後鎖住手動值。
- 放開滑桿、提交數值或切換自動模式時套用，並回讀驗證。驅動拒絕或回讀不符時顯示錯誤。
- 硬體控制透過相機擷取執行緒處理，避免跨執行緒操作相機控制介面。
- 「還原影像參數預設值」套用驅動預設數值；支援自動的項目啟用自動。這不會刪除設定檔或改變解析度。

硬體曝光與白平衡會改變保存的相機影像。影像工具中的預覽濾鏡仍不會改寫快照或錄影原圖。快照來源資訊包含擷取模式及最近回讀的硬體參數；自動參數會持續變動，這份紀錄不是逐幀同步的感測器 metadata。

目前使用 Windows DirectShow 的 IAMCameraControl／IAMVideoProcAmp；切換至 MSMF 或驅動未公開參數時，面板會說明無法提供影像調整，基本採集仍可使用。能力介面參考 [Microsoft 文件](https://learn.microsoft.com/en-us/windows/win32/directshow/configure-the-video-quality)。

## 設定檔

輸入名稱後按「儲存目前設定」。相機運作時保存實際回報的模式與影像參數；停止時保存表單要求設定及已載入的影像參數。同名設定檔會更新。

載入設定檔需先停止相機，再選取設定檔、按「載入設定檔」及啟動相機。啟動後重新檢查相容性，影像參數未套用成功時會顯示原因。

設定檔存於資料根目錄的 `camera-profiles.json`，每台裝置最多 50 個，名稱上限 80 字元。它屬於本機應用程式設定，不是專案備份的一部分。裝置以名稱與列舉索引區分；換 USB 接孔或裝置排序改變後，可能需要在新裝置項目重新儲存。

## 疑難排解

| 現象 | 建議檢查 |
| --- | --- |
| 設定 30 FPS，實測只有幾 FPS | 比較輸出格式與模式清單，檢查曝光時間、USB 連線及系統負載；不要只看驅動回報值。 |
| 選擇 MJPG 卻回報 YUY2 | 驅動可能未接受組合；選擇模式清單中的 FPS，重新套用並比較回報結果。 |
| 調整欄位沒有出現 | 確認已啟動相機；裝置或擷取後端可能不支援該硬體控制。 |
| 拖動滑桿卻套用失敗 | 依錯誤提示檢查回讀值；驅動可能在目前模式下拒絕調整。 |
| 畫面不流暢但擷取正常 | 提高預覽更新率，檢查影像處理耗時及 CPU 負載。 |
| 載入設定檔後參數未生效 | 檢查相機型號、裝置索引及目前可用範圍，重新儲存相容設定。 |

## 驗證範圍

本功能具備能力範圍與步進驗證、驅動拒絕與回讀不符、設定檔持久化及格式連動測試。桌面整合使用合成裝置，覆蓋曝光切換、輸出重啟、設定檔載入、固定底部操作列、預覽及採集生命週期。

2026-09-18 於 USB2.0 HD UVC WebCam 驗證 DirectShow 參數列舉、手動曝光設定與回讀，測試後還原原曝光模式。另確認格式最後套用後，1280 × 720／MJPG／30 FPS 的要求能正確回報，31 幀樣本的實測約 30.4 FPS。其他型號（包含 Razer Kiyo V2 X）仍需在對應硬體驗收，不承諾所有裝置具有相同參數或輸出模式。
