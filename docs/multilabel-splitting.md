# 多類別資料分割

資料分割管理預設使用「多類別綜合平衡」。同一張圖片的全部類別共同參與分配，圖片與其標註永遠屬於同一個集合。

## 平衡目標

- 綜合平衡：同時考量類別出現張數、物件數與常見共現配對。
- 出現張數：每張圖片對每個類別最多計一次，避免大量同類物件集中於少數圖片卻被視為充足。
- 物件數量：依框、遮罩等標註實例數量分配。
- 共現配對：在出現張數之外，加強同圖類別配對的分布，例如 A＋B、A＋C。配對不是硬性覆蓋要求。

來源隔離獨立於平衡目標。預設勾選時，拍攝批次、影片關聯與相同圖片形成完整群組；手動群組可明確指定批次內的獨立情境，但不拆開相同圖片或影片關聯。取消隔離後可逐圖分配，相同內容仍保持同組。請依實際資料來源判斷圖片是否獨立；演算法不會自動辨識近似影像。

## 預覽資訊

預覽顯示各集合實際張數、目標比例與百分點差距，以及每個類別的圖片數、物件數、原始來源群組數和實際分配群組數。來源群組數根據現有批次／影片記錄推算，並非經實際拍攝獨立性驗證。

稀少類別優先分配，Train 與 Validation 的類別覆蓋是套用條件；無法滿足時仍顯示阻擋原因。每組少於 5 張的提示是樣本稀少提醒，不是統計可靠性門檻。三張樣本各分一張並不代表已取得足夠訓練或評估資料。

分配使用多次稀少類別優先搜尋、單群組移動與有限群組交換，是啟發式近似，不保證全域最佳解。圖片比例、逐類比例與配對分布可能互相衝突。共現最佳化僅取至少出現於啟用集合數量那麼多張圖片的配對，依頻率保留最多 256 組；群組交換每輪最多考慮 48 個未鎖定群組。

預覽不會寫入圖片分割；確認後按套用才更新專案。固定種子、相同資料與設定可重現結果。既有固定資料版本不會被改寫；本次不增加過採樣、資料增強或訓練權重設定。
