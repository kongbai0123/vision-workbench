# 資料審核與匯入

匯入圖片或資料夾後，先在縮圖預覽勾選要加入專案的圖片，再按「匯入勾選圖片」。取消視窗不會加入資料；預覽一小時後失效，需要重新選擇來源。疑似模糊是以縮小影像的 Laplacian 變異數估算（門檻 80），僅供人工檢查，不會自動排除。低紋理圖片也可能出現提示。

資料審核中，點縮圖、檔名或卡片空白處都是勾選；鍵盤 Tab 聚焦卡片後也可用空白鍵或 Enter 勾選。「預覽」只放大檢查，「編輯標註」才進入編輯器。返回審核頁會保留勾選、篩選、分頁與捲動位置。切換專案或變更篩選條件會清除勾選；全選適用於目前篩選結果的所有頁面。

- 核准：允許納入新的訓練資料版本。
- 待修正：保留圖片與標註，回到待審核並記錄待修正原因。
- 排除訓練：保存模糊、曝光問題、重複、無關、遮擋過重或其他原因與備註。可以設為待審核後重新檢查。
- 移到垃圾桶：從目前專案清單移除，仍保留原圖、標註與歷史，可在垃圾桶勾選還原。還原後回到待審核；若同一圖片已重新匯入，會要求先處理重複項目。
- 永久刪除：從目前專案刪除選取圖片、標註與修訂紀錄，無法從資料審核垃圾桶還原。確認視窗會列出圖片數、標註數與已核准圖片數，避免誤刪。

外部原始來源檔案與既有固定訓練資料版本不受排除、垃圾桶或永久刪除操作影響。新的訓練需重新建立資料版本，才會套用最新審核結果。

「檢查模糊圖片」可以對已匯入圖片產生提示，再以「疑似模糊」篩選集中檢查。依排除原因篩選時，搭配「所有狀態」或「已排除訓練」查看相關圖片。
