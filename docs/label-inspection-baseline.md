# 貼標辨識與量測設計基準

## 已確認需求

- 同時辨識標籤圖案與文字、標籤位置，以及車把手物件輪廓。
- 標籤尺寸約 1～5 cm，可能貼在平面或車把手弧面。
- 工件拍攝時靜止，相機位置固定；人工會將貼標區轉至上方。
- 工件型號與弧面不固定，表面為拋光黑色碳纖維。
- 第一階段使用 Razer Kiyo V2 X；工業相機留待後續評估。
- 期望以毫米驗收，目標公差為 ±0.05～0.1 mm。
- 可以加入定位標記，但系統也要評估無標記流程。

## 工程判斷

目前回報的拍攝距離為 180～200 cm。以廣角網路攝影機在此距離取得完整畫面時，每像素通常對應約毫米量級，不能直接證明 ±0.05～0.1 mm 的量測能力。第一階段應將 Kiyo V2 X 定位為流程、辨識與資料採集驗證設備；精度必須以實際視野、校正板及連續影像重複性測試確認。

曲面標籤不能只用平面影像座標代表真實表面距離。固定型號可建立弧面校正模板；型號和曲率不固定時，應使用治具基準、個別產品配方，或後續加入近距離／3D量測設備。

## 建議辨識架構

1. 原始影像品質檢查：清晰度、曝光、反光、遮蔽與標籤像素尺寸。
2. 物件定位：取得車把手輪廓、方向與產品型號。
3. 標籤定位：保存 Mask、四角點、中心、角度及所屬物件。
4. 圖案與文字辨識：分開保存圖案類別、OCR結果與信心值。
5. 幾何換算：依相機校正、治具基準與產品弧面配方換算毫米座標。
6. 人工核准：低信心、反光或幾何超限資料必須進入人工審核。

## Marker策略

- 優先放在固定治具或拍攝平台，不將平面Marker強行貼在彎曲表面。
- Marker用於偵測相機位移、比例與旋轉漂移。
- 無Marker時，必須以定位銷、治具邊界或其他已知尺寸特徵作為實體基準。

## 光學與採集策略

- 使用大面積漫射光，避免小型直射光在碳纖維表面形成亮斑。
- 優先測試光源與鏡頭交叉偏光。
- 鎖定手動對焦、曝光及白平衡；靜態工件優先解析度而非FPS。
- 同一工件連拍多幀，計算角點與中心位置的標準差、P95及最大誤差。
- 處理演算法未完成校正或載入時，預覽必須回退原圖，不能中斷相機畫面。

## Vision Workbench落地順序

1. 建立相機配方與固定參數紀錄。
2. 加入校正板拍攝、畸變校正與實際視野量測。
3. 加入取像品質閘門與反光警示。
4. 建立物件、標籤、四角點、Mask、圖案及OCR的關聯標註。
5. 建立治具Marker與無Marker兩套驗證資料。
6. 以像素重複性先驗證Kiyo，再決定是否增加近距離或工業量測相機。
