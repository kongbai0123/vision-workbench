## 作業系統與 Python

Vision Workbench 支援 Windows 10／11（64 位元）。建立或重建桌面環境時，安裝腳本使用 64 位元 Python 3.13。已通過啟動檢查的 64 位元 Python 3.12–3.14 環境可繼續使用。首次安裝桌面套件需要網路。 [啟動與修復說明](startup-troubleshooting.md)

## 硬體與儲存規劃

以下數字為規劃起點。實際需求取決於影像解析度、批次大小及啟用的模型。

| 工作方式 | 硬體規劃 | 可用空間 |
| --- | --- | --- |
| 手動標註與資料審核 | 4 核心 CPU、8 GB RAM，可使用內建顯示晶片。GrabCut 互動分割可使用 CPU。 | 建議 SSD 預留 10 GB，專案資料另計。 |
| 本機 AI 批量找框 | 需要 NVIDIA GPU 與相容的驅動程式。批量流程已在 16 GB VRAM 的 GPU 上測試，最低可用 VRAM 仍待實測。 | 含批量執行環境與選配模型，建議預留約 30 GB，專案資料另計。 |

依專案規模另行預留原始圖片、影片、固定資料版本、訓練輸出及匯出檔案的空間。

## 離線安裝批量找框模型

先備妥包含 CUDA Python 執行環境、MM Grounding DINO 及 Qwen 權重的 `models/annotation-assist/` 資料夾。使用 SAM 2.1 框界檢查或 Gemma 4 觀察覆核時，還需各自的選配檔案。

在新電腦的「設定 → 模型與元件」按「從資料夾安裝批量模型」，選擇已備妥的資料夾。設定頁會列出檔案狀態，推論開始時會檢查模型及執行環境。 [批量模型套件與搬移方式](model-assistance-workflows.md)
